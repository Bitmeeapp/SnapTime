# ⚡ Snap Time - Daily Real Moments Sharing App

Snap Time ek Gen Z focused Daily Real Moments Sharing application hai. Yeh traditional filters aur artificial photo-editing ke bajaye authentic real-time moments capture karne ke liye banayi gayi hai.

## ✨ Key Features
- ⚡ **Daily Random Alert System:** Unpredictable daily capture notifications.
- 📸 **Dual Camera Capture:** Simultaneous front selfie + back environment view.
- 🎙️ **10s Voice Vibe Drop:** Express feelings with short ambient audio notes.
- 🔥 **Streak Tracker & Inner Circle:** Keep track of daily real captures with close friends.
